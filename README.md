# 📹 Spring Boot Backend for Zoom Video SDK

This project provides a Spring Boot REST API that integrates with the Zoom Video SDK. It handles session creation, JWT generation, and client coordination for video calls.

---

## 🛠 Features

- ✅ Generate Zoom JWT using app key & secret
- ✅ Create and update Zoom sessions
- ✅ Validate session data
- ✅ Layered architecture (Controller, Service, Gateway)
- ✅ Swagger/OpenAPI documentation
- ✅ Snake_case JSON support

---

## 📦 Tech Stack

- Spring Boot 3.x
- Java 17+
- Jackson (with snake_case mapping)
- Springdoc OpenAPI (Swagger)
- Zoom Video SDK (via REST API)
- Lombok
